Design and build a premium, modern, futuristic frontend website for “ASTHRA”, a technology/department organization.

This is for a UI/UX competition, so prioritize exceptional visual design, user experience, responsiveness, navigation, typography, animations, accessibility, and overall presentation.

The website must be a fully functional clickable frontend that runs in a browser, not a static design or image mockup. No backend, database, authentication, or admin panel is required. UIUX-Rulebook.pdf

Brand Identity

Use the provided ASTHRA logo as the primary brand identity.

Create a visual language inspired by:

* Artificial intelligence
* Electronics and circuit boards
* Innovation
* Technology
* Engineering
* Digital creativity

Use the logo’s cyan, electric blue, violet and magenta neon gradient as inspiration, but keep the interface sophisticated rather than overly cyberpunk.

Design Direction

Create a premium futuristic university/technology organization website.

Visual characteristics:

* Dark sophisticated background
* Cyan/blue/purple accent lighting
* Glassmorphism used subtly
* Soft gradients
* Fine circuit-inspired patterns
* Large editorial typography
* Clean spacing
* Rounded cards
* Smooth hover interactions
* Subtle scroll animations
* Elegant micro-interactions
* Strong visual hierarchy
* High-quality generated/stock imagery

Avoid making every section glow excessively. The design should feel professional, innovative and competition-ready.

Required Pages

1. Home

Create an impressive landing page introducing ASTHRA.

Include:

* Sticky navigation bar
* ASTHRA logo
* Navigation links
* Hero section
* Strong headline
* Short introduction
* CTA buttons
* Short mission section
* Vision section
* Inspirational technology quote
* Featured activities
* Latest newsletter
* Call-to-action section
* Footer

The footer must contain:

* Instagram link
* Email/contact
* ASTHRA branding

The rulebook specifically requires an introduction, mission/vision, quote and footer with Instagram and email. UIUX-Rulebook.pdf

Make the homepage feel like the main showcase piece of the competition.

⸻

2. Activities

Create an activities/events listing page.

Display activities using visually attractive cards.

Every card must contain:

* Event image
* Event title
* Date
* Short description
* View Details button

Use realistic fictional ASTHRA events such as:

* AI Innovation Summit
* CodeSprint
* TechNova
* Cybersecurity Awareness Workshop
* Design Thinking Bootcamp
* Robotics Challenge

The rulebook requires past events with a photo, title and date. UIUX-Rulebook.pdf

Add filtering/categories if it improves the UX.

⸻

3. Activity Details

Clicking an activity card must open a dedicated details page or polished modal.

Include:

* Large event image
* Event title
* Date
* Full description
* Event highlights
* Additional photos/gallery
* Back to Activities button

The interaction must actually work when the website is opened in a browser. UIUX-Rulebook.pdf

⸻

4. Newsletters

Create a newsletter archive page.

Display newsletters as premium magazine-style cards.

Each card should include:

* Newsletter cover
* Title
* Date
* Short description
* Read More button

Example fictional newsletters:

* ASTHRA Pulse — January 2026
* The Innovation Issue — February 2026
* Tech Horizons — March 2026
* Inside ASTHRA — April 2026

5. Newsletter Details

Clicking a newsletter should open a detailed newsletter page.

Include:

* Title

* Description
* Highlights

The rulebook specifically requires the newsletter detail view to contain a description and Download PDF button. UIUX-Rulebook.pdf

UX Requirements

Make the website:

* Fully responsive on mobile, tablet and desktop
* Easy to navigate
* Consistent across every page
* Fast and visually clean
* Accessible
* Keyboard-friendly
* Clearly clickable
* With visible hover/focus states
* With smooth page/section transitions

The competition explicitly requires the website to work well on both laptop and phone screens. UIUX-Rulebook.pdf

Navigation

Desktop:

ASTHRA Logo | Home | Activities | Newsletters | Committee | Contact

Mobile:

Use a clean hamburger navigation.

Make sure:

* Logo links to Home
* Cards are clickable
* Back navigation works
* CTA buttons work
* Newsletter download works
* External LinkedIn/Instagram links work

⸻

Creative UI/UX Enhancements

Add tasteful competition-level touches such as:

* Animated circuit lines in the hero
* Subtle glowing cursor interaction
* Scroll-triggered reveal animations
* Interactive activity cards
* Newsletter carousel
* Animated statistics
* Timeline for committee years
* Image gallery lightbox
* Smooth page transitions
* Magnetic/animated CTA buttons
* Custom loading animation using the ASTHRA logo

Do not overuse animations. They should enhance the experience rather than distract from the content.

⸻

Content

All content can be fictional but should look realistic and professional. The rulebook explicitly permits realistic sample content and free stock/placeholder/AI-generated images. UIUX-Rulebook.pdf

Do not copy an existing real website. Create an original visual identity and layout. UIUX-Rulebook.pdf

⸻

Technical Requirements

Build this as a working frontend website.

Use:

* React / Next.js
* TypeScript
* Tailwind CSS
* Reusable components
* Responsive layouts
* Local/static data for activities, newsletters and committee members

No:

* Backend
* Database
* Login
* Admin panel
* Authentication

Keep all required data in frontend/static data files.

⸻

Final Competition Experience

When a judge opens the website, the experience should immediately communicate:

“This is a modern technology organization built around innovation, creativity and people.”

The homepage should make a strong first impression, while the Activities, Newsletters and Committee sections should demonstrate strong information architecture and UX design.

Prioritize UI/UX quality over unnecessary technical complexity.

Make the final website look like a real professional ASTHRA department website, not an AI-generated template.
